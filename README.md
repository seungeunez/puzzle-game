# 퍼즐 게임

이 게임은 `4x4` 크기의 과일 카드 맞추기 게임이에요.

URL: https://puzzle-game-lyart-gamma.vercel.app/

## 게임 설명

- 모두 16장의 카드가 있어요.
- 카드에는 과일 그림이 하나씩 있어요.
- 똑같은 과일 그림 카드 2장을 맞추면 그 쌍은 맞춘 것으로 남아요.
- 8쌍을 모두 맞추면 게임이 끝나요.

## 어떻게 놀아요?

1. 게임을 시작하면 카드가 모두 뒤집혀 있어요.
2. 첫 번째 카드를 클릭하면 카드 앞면이 보여요.
3. 두 번째 카드를 클릭하면 또 다른 카드 앞면이 보여요.
4. 두 카드가 같은 과일이면 그 카드는 계속 앞면으로 남아요.
5. 두 카드가 다르면 잠시 보여주고 다시 뒤집혀요.
6. 8쌍을 모두 찾으면 승리 메시지가 나와요.

## 게임 화면에 무엇이 있어요?

- 카드판: 카드가 4줄 x 4칸으로 모여 있어요.
- 시도 횟수: 카드를 두 장 선택할 때마다 1씩 올라가요.
- 짝 맞춘 개수: 지금까지 맞춘 과일 쌍 수를 보여줘요.
- 최고 기록: 가장 적은 시도로 게임을 완성한 기록이에요.
- 메시지: 다음에 무엇을 하면 좋을지 알려줘요.

## 코드가 어떻게 동작하나요?

### `js/config.js`

- 게임판 크기 `BOARD_SIZE = 4`로 정해요.
- `STORAGE_KEY`는 최고 기록을 저장할 때 쓰는 이름이에요.
- `PAIR_MISMATCH_DELAY`는 틀렸을 때 카드가 다시 뒤집히기까지 기다리는 시간이에요.

### `js/fruits.js`

- 게임에 사용할 과일 정보를 모아 놓았어요.
- 과일마다 `key`, `label`, `image`, `backColor`가 있어요.
- 예: `apple`, `banana`, `grape` 등 여러 과일이 있어요.

### `js/state.js`

- `gameState`는 지금 게임 상태를 담아요.
- 어떤 카드가 있는지, 어떤 카드가 선택되었는지, 시도 횟수, 맞춘 쌍 수를 기억해요.
- `resetGameState()`는 새 게임을 시작할 때 상태를 초기화해요.

### `js/game.js`

이 파일은 게임 규칙을 만들어요.

- `startNewGame()`는 새 게임을 시작해요.
- `buildDeck()`는 과일 카드 8가지씩을 2장씩 만들어서 16장을 만들어요.
- `shuffleCards()`는 카드를 섞어요.
- `handleCardClick()`은 카드를 클릭했을 때 실행돼요.
- `resolveSelection()`은 두 장을 선택했을 때 같은지 다른지 확인해요.
- `markPairAsMatched()`는 같은 카드일 때 그 쌍을 맞은 것으로 처리해요.
- `scheduleMismatchReset()`는 틀리면 잠시 뒤 카드가 다시 뒤집히게 해요.
- `handleClear()`는 모두 맞추면 게임이 끝났다고 알려줘요.

### `js/ui.js`

- `renderBoard()`는 화면에 카드를 그려요.
- `createCardButton()`은 각 카드를 버튼으로 만들어요.
- `updateScoreboard()`는 시도 횟수와 맞춘 개수를 보여줘요.
- `setMessage()`는 화면 아래에 안내문을 보여줘요.
- `loadBestScore()`와 `saveBestScore()`는 최고 기록을 저장하고 불러와요.
- `showClearDialog()`는 게임이 끝났을 때 알림 창을 보여줘요.

## 플레이어가 보는 흐름

1. 페이지를 열면 `js/main.js`가 실행돼요.
2. `startNewGame()`가 호출돼서 새 카드 덱을 만들어요.
3. `renderBoard()`가 카드판을 화면에 보여줘요.
4. 사용자가 카드를 클릭하면 `handleCardClick()`가 작동해요.
5. 두 장을 비교해서 같으면 맞춘 것으로 남고, 다르면 다시 뒤집어요.
6. 8쌍을 모두 맞추면 `showClearDialog()`가 나타나요.

## 새 게임 버튼

- `새 게임` 버튼을 누르면 카드가 섞이고 시도 횟수가 0이 돼요.
- 게임 화면과 점수판이 초기 상태로 돌아가요.
